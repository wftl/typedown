# Welcome to TypeDown

A beautiful, distraction-free markdown editor for Linux.

---

## Features

- **Live preview** — the right pane updates as you type
- **Split view** — edit on the left, rendered preview on the right
- **Focus mode** — hide all chrome with `Ctrl+Shift+F`
- **Dark theme** — toggle with `Ctrl+Shift+D`
- **Export** — save as HTML or PDF from the File menu
